# Assessment V0 — Agentic AI Engineer Live Proof-of-Work

**Governing issue:** [#184](https://github.com/tbhrc/drf-main/issues/184)  
**Purpose:** produce auditable evidence for Talent Bridge verification before marketplace build  
**Status:** v0 design / TEST

## Principle

Do not ban AI tool use. Agentic AI engineering competence includes knowing how to use AI safely and effectively.

The assessment should observe **process + output + judgement**, not final answers alone.

## Candidate experience

The candidate can complete the assessment through the most suitable modality:

- voice-led discussion plus observed execution;
- text-led interaction plus repository/output inspection;
- screen-share/video where appropriate;
- asynchronous proof review only as supporting evidence, not the full certification.

Do not penalise accent, camera comfort, typing speed or presentation polish unless the role genuinely requires those behaviours.

## v0 flow

```text
1. consent + role context
2. candidate evidence intake: CV / LinkedIn / GitHub / projects
3. live scenario briefing
4. candidate problem framing
5. AI-assisted build/planning session
6. output inspection: repo, script, workflow, architecture, logs, tests or demo
7. adaptive change/failure prompt
8. debugging / recovery / trade-off explanation
9. rubric scoring
10. bounded human technical review
11. pass/reject + evidence pack
```

## Example scenario families

Use one scenario matched to seniority and role target:

1. **Agent workflow build** — design a small agentic workflow that takes messy input, calls tools/functions and produces a governed output.
2. **RAG/context system** — design retrieval/context handling, evaluation and failure controls for a business knowledge task.
3. **Forward deployed AI task** — convert a business problem into a deployable AI-assisted workflow with handoff, metrics and risks.
4. **Existing project review** — inspect/improve a candidate's prior AI project and introduce a change/failure case.

## Competency rubric

| Dimension | Weight |
|---|---:|
| Problem framing and decomposition | 15% |
| Agent architecture / orchestration / tool-use design | 15% |
| Software engineering and implementation quality | 15% |
| Context, RAG, state and data design | 10% |
| Evaluation, testing and observability | 15% |
| Security, privacy, guardrails and failure handling | 10% |
| AI collaboration / prompt-tool judgement | 10% |
| Technical ownership, explanation and trade-off reasoning | 10% |

## Scoring band

| Band | Meaning |
|---|---|
| 85–100 | Talent Bridge Verified — strong evidence for shortlist use |
| 75–84 | Conditional / role-specific verification only after human review |
| 65–74 | Hold — promising but not directory-ready |
| <65 | Reject for verified pool; may reattempt later with new evidence |

## Evidence pack

Private evidence pack should include:

- candidate consent status;
- role target;
- scenario used;
- accepted prior proof links/artifacts;
- transcript/notes summary;
- output artefacts or repository link;
- rubric scores;
- pass/reject rationale;
- human review notes;
- public-profile fields approved by candidate;
- expiry/revalidation date.

## Human-review boundary

AI may generate prompts, inspect outputs, draft evidence summaries and suggest scores. Final commercial verification/rejection must include human review until enough outcome evidence proves automation reliability.

## Privacy/fairness controls

- separate public profile consent from private assessment evidence;
- no phone/email public by default;
- no emotion, accent, facial or personality inference;
- candidate can correct factual profile errors;
- candidate can request a retest window;
- do not expose raw transcripts to employers unless explicitly consented and useful;
- store scoring reasons, not only numeric scores.

## v0 cohort proof

Run **10 candidates**.

Track:

- source channel;
- completion rate;
- pass rate;
- review time per candidate;
- score distribution;
- candidate feedback;
- employer response to evidence pack;
- interview requests;
- paid commitment outcome.

**Pass:** at least 3 verified candidates, at least 2 employer interview/conversation requests and at least 1 employer willing to proceed on paid Talent Bridge terms.
