## Business definition

> We sell a bounded AI-first outsourced IT department to UAE SMEs for onboarding plus recurring per-user MRR because routine employee support, Microsoft 365 administration, joiner/leaver work, endpoint hygiene and monitoring recur continuously but many small firms cannot justify a full internal IT team. AI/deterministic automation handles approved repetitive work first; qualified humans/partners handle privileged exceptions, on-site work and higher-risk engineering.

This is not generic workflow automation. The buyer is purchasing an ongoing IT support/SLA outcome with privileged administration and recurring employee demand.

## Delivery architecture

```text
employee request / proactive alert
→ identity + client policy check
→ deterministic approved workflow where possible
→ bounded AI diagnosis/knowledge
→ privileged-action approval gate
→ human/partner escalation for exceptions/on-site/security
→ ticket + audit record
→ monthly outcome/automation report
```

Least privilege, auditable changes and client-owned tenant/admin boundaries are mandatory.

## Return profile

**DRF actual revenue:** none.

## Risks / boundaries

- UAE MSP competition is dense; lower labour cost alone is not differentiation.
- No open-ended autonomous privileged changes.
- UAE personal-data/confidentiality obligations require appropriate client/processor controls.
- On-site, network, hardware, cyber incident and obscure LOB-app work require qualified human delivery.
- Keep the system/provider stack replaceable; sell managed outcome and reliability.
